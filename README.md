# Caisse Vesuvio

Application de gestion des encaissements journaliers pour la pizzeria Le Vesuvio.

## Objectif

Reconstruction moderne de l’application de caisse :

- Saisie Midi et Soir
- Archivage des encaissements
- Contrôle des écarts
- Fond de caisse
- Comptabilité mensuelle

## Stack technique

- HTML / CSS / JavaScript
- Supabase local pour la base de données
- Git et GitHub pour le versioning
- Vercel pour le déploiement futur
